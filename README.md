## 📖 About

**nazz UI Code Snippets** is a collection of loaders, buttons, cursors, galleries, and visual effects from the [nazz Code](https://www.youtube.com/@nhossaincse) YouTube channel.

Every demo is dependency-free (aside from the occasional Google Font or CDN library like GSAP), copy-paste friendly, and designed to be picked apart, learned from, and dropped straight into your own projects.

- 🎯 **Zero setup** — each snippet is one HTML file, viewable directly in a browser
- 🧩 **Copy-paste ready** — grab the markup, styles, and script as one unit
- 🎨 **Real, polished UI** — not toy examples; production-quality visual detail
- 📱 **Built for the web** — pure HTML/CSS/JS, no framework lock-in

## 🚀 Quick Start

Clone the repository:

```bash
git clone https://github.com/nhossaincse/nazz-ui-code-snippets.git
cd nazz-ui-code-snippets
```

Open any snippet directly in your browser:

```bash
open snippets/006-nazz-pencil-loader.html      # macOS
start snippets/006-nazz-pencil-loader.html     # Windows
xdg-open snippets/006-nazz-pencil-loader.html  # Linux
```

Or serve the folder locally for a smoother experience (recommended when a snippet uses relative assets or fetch):

```bash
npx serve .
# then visit http://localhost:3000/snippets/
```

## 🛠️ Tech Stack

| | |
|---|---|
| **Markup / Styling** | HTML5, CSS3 (custom properties, `clip-path`, 3D transforms, `backdrop-filter`) |
| **Scripting** | Vanilla JavaScript, Canvas API, SVG |
| **Animation** | CSS keyframes/transitions, [GSAP](https://gsap.com/) (+ ScrollTrigger, MotionPath) where noted |
| **Fonts** | Google Fonts, loaded per snippet via CDN |
| **Build tooling** | None — every file runs standalone |

## 🤝 Contributing

This repo primarily mirrors demos built for the nazz Code channel, but improvements are welcome:

1. Fork the repository
2. Create a branch: `git checkout -b feature/your-snippet-name`
3. Add your snippet as a single, self-contained file under `snippets/`
4. Open a pull request describing the effect and any credits/inspiration

Keep snippets dependency-light, accessible where practical, and consistent with the "one file, no build step" spirit of the collection.
